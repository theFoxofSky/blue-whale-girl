# 蓝色大肥鱼 · Mac 桌宠

原生 AppKit 应用，全部动画在本机播放，无需 API key。

![蓝色大肥鱼](teaser.png)

## 构建

需要 macOS 13 或更新版本，以及 Apple Command Line Tools（`xcode-select --install`）。

```sh
zsh build.sh
open .build/蓝色大肥鱼.app
```

默认构建当前 Mac 的架构。可通过 `PET_ARCH=arm64` 或 `PET_ARCH=x86_64` 交叉构建；`PET_OUTPUT` 可指定绝对 `.app` 输出路径。

## 互动

- 轻触头部或在头部移动鼠标可以摸头；点击碗喂白米饭。
- 摸头播放一遍；打招呼用 8 个不同姿势组成 12 步动作，抬手、左右摇手再收手，约 1.68 秒完成一轮。
- 鼠标在附近围着脑袋连续转动超过 5 圈，她会坐下变成圈圈眼，头顶星星环绕，约 5 秒后恢复。顺时针、逆时针都可以，恢复后可立即重新绕圈；左右晃动不会累计圈数，中断或移远会重新计数。
- 闲暇时每隔约 45–75 秒举碗等待一次，也可以点击菜单“举碗要饭”立即播放。
- 可以拖动、散步、睡觉、唤醒、调整大小和置顶。
- 撒娇播放一次打滚，全程没有文字气泡。每 30 秒判断一次，自动打滚与追逐各占 4%，合计最多 8%。
- 追逐最长 6 秒；按下鼠标即可打断。两分钟没有互动会自动打盹。
- 只有手动拖到左右边缘才会躲起来；散步到边缘会转向，追逐到边缘会停下。可以拖着脑袋到左右下角，单击才会出来。
- 睡着后忽略鼠标移动，点击角色或菜单“叫醒”才能唤醒。
- 站立时每隔 6–10 秒眨眼一次，持续约 0.16 秒。
- 16 个转头方向共用身体比例和脚底位置。原有 103 帧保持原样，另有 1 张高清头晕坐姿、4 张高清挥手过渡帧；全部直接渲染到屏幕。

## 打包

完整回归通过后运行 `python3 scripts/package.py`，生成 `dist/` 下的安装包、源码包和 SHA-256 清单。打包前会核对当前源码与素材是否匹配回归结果。

## 目录

- `Sources/`：桌宠行为、原生窗口、输入和绘制。
- `Tests/`：模型回归、素材检查和高清素材指纹。
- `HighResolution/`：103 帧无损 WebP、头晕与挥手 PNG 和显示位置配置，构建所需素材全部随仓库保存。
- `Assets/`：菜单图标、探头与打滚原画和来源说明。
- `scripts/`：回归、独立构建验证、打包和本机实例管理。
- `Docs/`：预览与已完成的回归记录。

构建缓存、应用包、安装压缩包和测试输出均已加入 `.gitignore`。创作阶段的旧素材、旧脚本和历史版本保存在本地项目旁的 `archive/`，不参与构建。

菜单栏鲸鱼图标来自 [DeepSeek 官方仓库](https://github.com/deepseek-ai/DeepSeek-LLM/blob/main/images/logo.svg)，来源与原始 SVG 保存在 `Assets/`。
